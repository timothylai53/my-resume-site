summary report.

3. DETERMINE MATCHING KEY
==================================================

After selecting/processing a Medium dataset, use a decision:

Which Medium dataset is being processed?

Branch A:

PT / IVS / AVS

Use:

Current Sheet[Unique Reference ID]

as the lookup key.

Branch B:

CVE

Use:

Current Sheet[Unique ID (SPM+Hostname)]

as the lookup key.

IMPORTANT:

Do NOT use the normal Unique Reference ID matching method for CVE.

For CVE the current-sheet composite identifier:

Unique ID (SPM+Hostname)

must be used.

5. MATCH FOUND?
==================================================

After performing the lookup, add a decision:

Matching record found?

YES
→ Continue to monthly field enrichment.

NO

Do NOT silently ignore unmatched identifiers.

Then preserve the record for review.

8. MONTHLY LOOKUP 3
PLANNED REMEDIATION MONTH
==================================================

Retrieve:

ROWG Detailed Dataset[Remediation Planned Date]

Then process the returned value.

If it is a valid date:

Convert it to:

yyyy-mm

Examples:

15-Sep-2026
→ 2026-09

31-Dec-2026
→ 2026-12

23-Jun-2027
→ 2027-06

Write the result to:
