==================================================

IMPORTANT:

Keep the spelling "Prioty" where referring to the existing report/template.

Inputs:

IBS
Business Function / Mapped Business Function
CJ or IF
Final Severity Rating


First:

Are required Priority inputs present?

If NO:
    Prioty = blank

If YES:
    continue


Then apply Severity eligibility.

Eligible:

Critical
High
Medium ONLY when Mapped Business Function = PT

Not eligible:

Low
Medium + IVS
Medium + AVS
Medium + CVE
other noneligible severity

If not eligible:

Prioty = blank


If eligible, evaluate in this EXACT ORDER:

1. CJ or IF = IF-CJ
   → P1

2. CJ or IF = IF
   AND IBS = IBS
   → P1

3. CJ or IF = IF
   AND IBS = Non-IBS
   AND Mapped Business Function = IVS or AVS
   → P2

4. CJ or IF = IF
   AND IBS = Non-IBS
   AND Mapped Business Function = CVE or PT
   → P1

5. CJ or IF = CJ
   → P2

6. CJ or IF = Others
   AND IBS = IBS
   → P2

7. CJ or IF = Others
   AND IBS = Non-IBS
   AND Mapped Business Function = IVS or AVS
   → P4

8. CJ or IF = Others
   AND IBS = Non-IBS
   AND Mapped Business Function = CVE or PT
   → P3

If the record is eligible but inputs are present and cannot be mapped/matched:

Prioty = Check Input


Include a simplified Prioty matrix in or alongside the diagram:

Condition                IVS   AVS   CVE   PT

IF-CJ                    P1    P1    P1    P1
