I now want to define the PivotTable-style summary/reporting requirements for
the Vulnerability Management Reporting Automation System.

These summaries currently exist in Excel PivotTables.

The web application should reproduce the same analytical logic, but the UI
should be more interactive and reusable rather than creating a separate page
for every PivotTable.

IMPORTANT:

Use the processed dataset after enrichment/calculated fields have been
generated.

Do NOT calculate dashboard totals from the raw unprocessed dataset.

==================================================
GENERAL COUNTING RULE
==================================================

Throughout these reports:

"Number of Vulnerability"

means:

COUNT OF UNIQUE REFERENCE ID

Use:

distinct count of Unique Reference ID

Do NOT use normal row count if duplicate Unique Reference IDs can exist.

The dashboard/API should use the same counting definition consistently.


==================================================

==================================================

For summaries 1-4, the normal row hierarchy is:

==================================================
UNPLANNED REMEDIATION
==================================================

Confirmed rule:

If Remediation Planned Date is blank:

Remediation Plan classification = Unplanned

Unplanned should appear as a separate reporting category.

Do not assign an artificial month or quarter to an Unplanned record.


==================================================
FILTER BEHAVIOR
==================================================

I do NOT want to reproduce Excel PivotTables literally.

The web application should provide interactive filter controls.

The user should be able to select one or multiple values from the applicable
filter fields.

Where appropriate, include:

- All
- individual values
- multiple selections
- Clear Filter / Reset Filters

When filters change:

- summary table updates;
- totals update;
- charts update;
- Grand Total updates.

Do NOT require page reload.
