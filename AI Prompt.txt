These are all the business rules the system applies right now, in the order it applies them.

1. Validation (before processing)

Problems are reported; records are never removed.

Validation fails, so the file can't be processed, when:
- the Raw Data sheet is missing;
- row 1 doesn't contain the column headers;
- a column name appears twice;
- the sheet has no records;
- any of these 13 required columns is missinry, CIID, Business Function, Final SeverityRating, Remediation Status, Remediation Domain, Remediation Domain Grouping, ICS Hierarchy, CJ or IF, SLA Due Date,
  Report End Date, Remediation Planned Date.

Warnings, where the records are kept but flagged:
- a missing Unique Reference ID, or one that appears more than once;
- a date value that can't be read as a date;
- a blank Country, CIID, Business Function, ng, Remediation Status, Remediation Domain or Report End Date;
- a blank SLA Due Date when SLA Category isn't "No SLA";
- a Country that isn't in the cluster mappin
- a Business Function that doesn't map;
- a CJ or IF value other than IF-CJ, IF, CJ or Others;
- more than one Report End Date in the file (one upload should be one reporting period).

cepted text date formats: 2026-12-31, 31/12/2026 (day first), 31-Dec-2026 and 31 Dec 2026. Real Excel date cells always work.

2. Data cleaning

None yet. The cleaning step exists, but it's empty until you send the rules, so every record is kept.

Cluster (from the Country column)
- More than one country in the cell (separat
- One country → the cluster from your mapping sheet (35 countries; for example Australia → ASEAN)
- Blank → NA
- Not in the mapping → Unmapped, flagged

IBS (from CIID)
- CIID on the IBS sheet → IBS
- Not on it → Non-IBS
- Blank → blank
- Matching trims surrounding spaces and is o

Mapped Business Function
- Contains "CSR" (case doesn't matter) → IVSAVS → AVS, IVS → IVS, PT → PT, SPM → CVE
- Anything else → unmapped, flagged
