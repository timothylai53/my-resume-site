==================================================
PROJECT PURPOSE
==================================================

This system automates an existing Excel-based vulnerability management reporting workflow.

Currently, the workflow involves:
- Receiving raw vulnerability datasets
- Matching records using Unique Reference ID
- Retrieving additional vulnerability/remediation information
- Cleaning and standardizing data
- Applying country/cluster mappings
- Applying business-function mappings
- Calculating Within SLA status
- Assigning vulnerability priorities
- Processing planned remediation dates/months
- Generating PivotTable-style summary analysis
- Producing vulnerability/remediation reports

The objective of this application is to allow a user to upload raw data and have the application automatically process the dataset, apply the business rules, generate reporting summaries, and display the results through the frontend dashboard.
